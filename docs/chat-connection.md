## TL;DR
聊天在整个编辑器会话中保持连接，提供未读角标和成员上线/离开消息，加载提示居中且不挤动列表。

## Details

设计跟踪：https://github.com/DefeatMan/codingbox/issues/5

### 范围和验收

- 进入编辑器即连接 public；隐藏侧栏、切换面板或编程语言均保留连接。
- 实时用户消息在聊天不可见或页面处于后台时增加未读；打开前台聊天清零。历史、Git、系统事件不增加未读，同名参与者的消息不被误过滤。
- 仅保留 public，移除频道切换并拒绝 private 请求。旧 private 文件不删除、不公开，也不并入 public。
- 成员按认证会话识别，同一会话多个标签只计一名成员，同名不同会话分别记录。最后一个连接断开后缓冲 2 秒，期间重连不刷上线/离开消息。
- 系统事件显示“名字 已上线／已离开”并保留历史，描述服务端可见的聊天连接状态，不断言用户本人是否在线。
- 加载/重连提示使用消息区域正中浮层，列表位置和高度保持不变；加载期间不误显示空状态。
- 不增加跨设备已读持久化、全局连接池或额外频道连接。

### 依据与机制

观测：上游 `IDE.tsx:1222` 条件渲染 Chat，`useChat.ts` effect 清理关闭 WebSocket，因此离开面板就断连。正式环境临时房间三轮测量：点击后连接就绪约 1.3 秒；Box 内收到历史 9–89 毫秒，公网 0.79–0.94 秒。证据在忽略目录 `.data/app-chat-timing.json`、`.data/app-chat-local-timing.json`，仅覆盖 0–1 条消息。

[React useEffect 的 Parameters](https://react.dev/reference/react/useEffect#parameters) 说明依赖变化及卸载会执行清理；[Sharing State Between Components 的 Lifting state up](https://react.dev/learn/sharing-state-between-components#lifting-state-up-by-example) 建议共同父组件持有共享状态。因此把 useChat 提升到 IDE，向 Chat 传递状态，同时服务侧栏角标。可见性只改变已读状态，不作为连接 effect 依赖。仅 CSS 隐藏 Chat 无法解决外层侧栏卸载；保持整个侧栏挂载又会改变无关面板生命周期，因此不采用。

上游 `chat.go:584–620` 在认证后取得用户名并注册/注销 peer；`auth.go:416–451` 定义认证凭据来源和可信用户名。采用会话 token 的摘要作成员标识，避免同名合并或在事件里暴露 token。成员引用计数、代次检查和可取消定时器防止多标签和短暂重连刷屏；关闭 Hub 清理定时器。复用 Hub 锁排序历史及广播，沿用系统事件持久化；姓名去掉控制字符，防止系统日志换行注入。

前端始终显示 system 事件，不受 Git 噪声开关影响。绝对定位的加载浮层不占文档流、不拦截指针，已有消息仍可阅读和滚动。

### 验证

- 旧镜像分别复现未打开 Chat 时无连接、缺少上线消息。
- 新增浏览器用例检查预连接、角标增长和清零、同名参与者、模拟后台可见性、侧栏/语言切换不重连、public-only、成员上线和最后标签离开、短暂重连无重复事件，以及加载时消息坐标不变、提示文本居中。
- Go 测试检查会话复用、同名不同人、延迟离开、过期定时器、持久化、控制字符、凭据摘要和关闭清理，运行 race detector。
- 保留共享聊天、多行、历史和重连回归，构建真实编辑器镜像并检查类型。局部 lint 的既有 IDE 错误独立报告，不扩展到无关清理。
- 先在 dev 验证，再更新 app；运行中的房间不强制重启。
